Anthropic API key

Required to extract studies from sites without a hand-rolled scraper. Get a key from console.anthropic.com and paste it below. The key stays in your browser (chrome.storage.local) and is sent only to api.anthropic.com.

What this enables

  • Sites with a hand-rolled scraper: always free, run as today.
  • All other Browsable sites: each scan grabs the page text and sends it to Claude Haiku for structured extraction.
  • App-only sources (dscout, MeThinks, Mindswarms, Field Agent): not scrapable from a browser; listed for visibility only.

Cost

Estimated $9–$15 / month at 2 scans/day across ~48 sites, using claude-haiku-4-5. You can also disable LLM extraction per-source from the dashboard if a site consistently returns garbage. (Optional — the default scraper needs no API key.)
